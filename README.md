### 🧠 What I've Built

#### 🤖 [WhisperMind](https://github.com/koushal13/WhisperMind)
A **local AI chatbot** with **voice input**, **RAG document search**, and **full offline privacy**.  
Powered by **Ollama (Llama3, Mistral)**, **OpenAI Whisper**, and **pyttsx3 TTS**, WhisperMind turns your personal documents into an intelligent, private assistant.  
Supports PDF, DOCX, TXT, and Markdown — all processed locally with a clean Streamlit web UI.

> 🔒 Everything runs offline. Your data never leaves your machine.

#### ⚡ [FileForge](https://github.com/koushal13/FileForge)
A **privacy-first file conversion toolkit** built with Python and Flask.  
Converts images (HEIC, JPG, PNG, WebP, BMP, TIFF, GIF), merges/splits/compresses PDFs, and extracts text via OCR — with optional **AI-powered analysis** using Ollama.  
All processing happens locally; files never leave your device.

> 🖼️ iPhone HEIC → JPG, PDF merging, OCR, and AI analysis — all in your browser at localhost.

#### 📈 [MarketPulse-AI](https://github.com/koushal13/MarketPulse-AI)
A sophisticated **AI-driven stock market analysis platform** for swing traders.  
Features a Google-like stock search across NSE, BSE, TSX, NYSE, and NASDAQ; 8 data sources with automatic failover; 8 technical indicators (RSI, MACD, Bollinger Bands, ATR, etc.); real-time news sentiment analysis; and local LLM-powered BUY/HOLD/SELL signals via Ollama.

> 📊 Supports Indian, US, and Canadian markets. Beginner-friendly with plain-English AI explanations.

#### 🎯 [Jira AI Story Creator](https://github.com/koushal13/jira-standalone)
A free, open-source tool that transforms raw ideas into **professionally structured Jira issues** using AI.  
Write your story in any format; the Node.js + Express backend sends it to Ollama, which generates a proper user story with Given/When/Then acceptance criteria, then creates the issue directly in Jira Cloud via REST API.  
Includes a modern Web UI and a CLI for CI/CD automation.

> 🚀 From rough note to published Jira issue in seconds — with your original input preserved as a comment.

#### 🛢️ [SQL Server Health Check (DBMon)](https://github.com/koushal13/sql-server-healthcheck-poc)
A real-time **SQL Server monitoring platform** with automated problem detection, AI-powered explanations, and a FastAPI + Elasticsearch dashboard.  
Monitors 7 critical metrics: deadlocks, blocking chains, open transactions, slow queries, CPU/memory usage, TempDB health, and missing indexes — with 30-second auto-refresh and on-demand collection.

> 🔍 Works with Docker SQL Server, SQL Server Express, and Azure SQL. Powered by Python, FastAPI, and optionally Ollama for AI recommendations.

#### 🎭 [Playwright Demo](https://github.com/koushal13/Playwright)
A browser automation showcase built with **Playwright** and JavaScript.  
Demonstrates end-to-end testing across Chromium, Firefox, and WebKit — with trace capture, video recording, slow-mode UI, and HTML test reports.  
Includes a minimal demo script and a full-featured test spec for stakeholder walkthroughs.

> ✅ A practical reference for teams getting started with Playwright test automation.
